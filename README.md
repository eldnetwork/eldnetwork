# Eld

An L1 for ephemeral, content-addressed storage. Data is addressed by content key, kept only for a TTL, then expires by protocol.

[Website](https://www.eld.network) · [Docs](https://docs.eld.network) · [Explorer](https://explorer.eld.network) · [X](https://x.com/eld_network)
